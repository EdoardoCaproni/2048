    Policies retrained by experiments/export_viewer.py with the configuration and the seed of the best run of each method in the report. On the 2×3 board every policy is a table over the 27 022 decision states, and its P(win) is exact (policy evaluation by dynamic programming); on boards a learned table never visited, the corner rule plays. On the 4×4 board the page computes the n-tuple values and the network itself; the n-tuple agent uses the 4-tuple features (the 6-tuple network of the report weighs 134 MB).

    Project: 2048 as a Markov decision problem, Dynamic Programming and Reinforcement Learning, University of Siena.
